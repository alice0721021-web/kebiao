粘贴课表数据

支持带表头的 CSV / TXT。自动识别列名，例如： 班级名称,课程名称,教师姓名,教室名称,周期,星期,开始节,结束节
周期形如 7-14 或 5，星期 1=周一…7=周日；也支持每行一条竖线分隔文本。

添加课程

周期可填单周（如 5）或区间（如 7-14）。星期 1=周一…7=周日。

设置第1周周一日期

用于推算每周一到周日的具体日期，不影响课程数据。

每星期节数

超过当前节数的课程在导入时会被过滤，建议与课程数据匹配。

恢复课表备份

选择之前导出的 JSON 备份文件，恢复课程数据与设置。

修改课程

周期可填单周（如 5）或区间（如 7-14）。星期 1=周一…7=周日。

导入课表文件

选择 .csv / .txt 文件。自动识别表头列名（课程名称、教师姓名、教室名称、周期、星期、开始节、结束节，班级名称列可省略）。 周期形如 7-14 或 5，星期 1=周一…7=周日。导入失败会保留当前课表，不会清空。
